# VirtualList v1 Coverage Matrix

## Scope

VirtualList v1 wraps the official Foldkit `Ui.VirtualList` primitive as an installable registry slice. It covers fixed-height lists, variable-height lists, subscription-driven container measurement, scroll tracking, and programmatic `scrollToIndex` commands.

## Examples

- `virtual-list-basic`: fixed-height activity feed with a jump-to-middle action.
- `virtual-list-variable`: variable-height activity feed where every fourth row includes summary content.

## Guardrails

- Registry view tests verify unmeasured placeholders, measured rendering, fixed-window math, variable-window math, and command completion.
- Example scene tests drive measurement and jump-to-middle behavior through the real `ApplyScroll` command.
- Docs route tests verify page sections and example block IDs.
- Registry JSON is generated by `bun run build:registry` and checked by `bun run check:registry`.

## Out Of Scope

- Infinite loading and server pagination.
- Sticky headers or grouped rows.
- Prefix-sum caching for very large variable-height collections.
